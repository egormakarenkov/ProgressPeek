# Changelog

## 0.4.0-beta

- ProgressPeek naming, non-destructive legacy settings/usage migration and saved ETA preservation.
- First-run privacy/setup with explicit AI consent and status-only CLI checks.
- Per-user installer/uninstaller, optional desktop shortcut, portable/source allowlists and local checksums.
- Latest-task anchoring through historical scrolling and submitted additions; bounded outcome-aware retries and diagnostic freshness.
- Experimental ETA from existing estimates, plateau tolerance and per-task history; off for new installs.
- Themed wrapped tooltips, fitted status labels and monitor-aware visibility policy.
- Signed updater protections retained, identical verified release staging reused, rollback binaries retained.

Known limitations and release gates are documented in README.md and CLEAN-PC.md. No public license or publisher trust identity has been chosen.
